Как читать

  • Только вычисление — данные уже лежат в «родной» памяти реализации. Для WebAssembly это память модуля: чтобы туда попасть, пиксели надо скопировать.
  • С копированием — как в настоящем приложении: из ImageData в реализацию и обратно. У JavaScript копирования нет (он работает прямо с массивом), у WebAssembly оно входит в цену.
  • Реализации чередуются внутри каждого повтора, перед замером идёт прогрев, показана медиана. Замер в главном потоке вкладки: пока он идёт, страница не отзывается. Фоновые вкладки и энергосбережение искажают результат.
  • «Результат совпал» — байты результата JS и WebAssembly сравниваются целиком, а не «похоже».
